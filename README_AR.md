# منظف القرص C — نسخة متعددة اللغات

اللغات المرفقة: العربية، الإنجليزية، الصينية المبسطة، الفرنسية، الإسبانية، الهندية، والتركية. تعمل الترجمات دون إنترنت أو مفاتيح API. تتضمن هذه النسخة 129 رسالة لكل لغة، واختيار اللغة وحفظها، ومعالجة اتجاه العربية وتوصيل حروفها في عناصر Tk.

## التشغيل على ويندوز

يتطلب Python 3.8 أو أحدث مع Tkinter. يوصى بإصدار Python حديث من python.org.

```powershell
py -m venv venv
.\venv\Scripts\python -m pip install -r requirements.txt
.\venv\Scripts\python main.py
```

اختر اللغة من القائمة أعلى النافذة، ثم أغلق البرنامج وافتحه مجددًا لتطبيقها. يختار التشغيل الأول لغة النظام إذا كانت متاحة، وإلا يستخدم الإنجليزية. تحفظ اللغة في `%APPDATA%\CDriveCleaner\settings.json`، وليس داخل مجلد البرنامج. تظل خيارات المحاكاة والنسخ الاحتياطي كما كانت في الكود الأصلي.

لتشغيله بالعربية مباشرة من PowerShell:

```powershell
$env:CDRIVE_CLEANER_LANGUAGE = "ar"
.\venv\Scripts\python main.py
```

متغير البيئة يتقدم على الاختيار المحفوظ؛ احذفه إذا أردت تطبيق اختيار القائمة:

```powershell
Remove-Item Env:CDRIVE_CLEANER_LANGUAGE
```

## إضافة لغة أخرى

انسخ `locales/en.json` إلى ملف باسم رمز اللغة، مثل `locales/de.json`. غيّر `name` إلى اسم اللغة و`direction` إلى `ltr` أو `rtl`، ثم ترجم **القيم فقط** داخل `messages`. تبقى المفاتيح الأصلية كما هي. لا تغيّر متغيرات مثل `{v0}` أو `{v0:.2f}`، وحافظ على `\n` لفواصل الأسطر. احفظ الملف بترميز UTF-8. سيظهر الملف تلقائيًا في قائمة اللغات عند التشغيل التالي. تستخدم الرسائل الناقصة أو ذات المتغيرات غير الصحيحة الترجمة الإنجليزية.

إضافة ملف ترجمة تتيح اللغة الجديدة، ولا تعني أن جميع لغات العالم مترجمة بالفعل. اللغات السبع المذكورة هي المرفقة حاليًا. قد تتطلب أنظمة الكتابة الأخرى خطوطًا مناسبة ومعالجة عرض إضافية واختبارًا على النظام المستهدف.

## الاختبارات

```powershell
.\venv\Scripts\python -m unittest discover -s tests -v
```

تشمل الاختبارات اكتمال الرسائل، والمتغيرات داخلها، واكتشاف اللغات، وحفظ الاختيار واستعادته، والواجهة الرئيسية وإدارة النسخ الاحتياطية باللغات السبع. تستخدم اختبارات الواجهة بيانات وهمية ولا تحذف ملفات فعلية. على Linux تحتاج اختبارات الواجهة إلى شاشة أو Xvfb؛ تتخطاها أداة الاختبار عند غياب الشاشة.

تم التحقق من الواجهات على Linux باستخدام Python 3.13 وTk 8.6 مع Xvfb. تم بناء Windows EXE بنواة 64 بت باستخدام Python لويندوز عبر Wine على Linux، وفُحص فتح الملف التنفيذي وإغلاقه بنجاح باللغات السبع. لم يُختبر تنظيف قرص C على جهاز ويندوز فعلي. يلزم فحص النسخة على ويندوز قبل توزيعها، بما يشمل عرض الهندية والنصوص المختلطة داخل مربعات النظام الأصلية. سجلات المطور ورسائل نظام التشغيل ليست جميعها مترجمة بملفات الواجهة.

## بناء EXE على ويندوز

```powershell
.\venv\Scripts\python -m pip install -r requirements-build.txt
.\venv\Scripts\python build_exe.py
```

ينتج البناء `dist/CDriveCleaner.exe` كملف تنفيذي واحد، و`dist/CDriveCleaner-Windows-x64.zip` كحزمة محمولة مع التعليمات. يتضمن EXE ملفات `locales` والأيقونات، ولا يحتاج Python مثبتًا على جهاز المستخدم. لتشغيل النسخة المبنية افتح `CDriveCleaner.exe`. تحتفظ حزمة المصدر بالكود فقط ولا تتضمن البرنامج التنفيذي القديم. نقطة التشغيل المعتمدة هي `main.py` بواجهة Tkinter. الملف القديم `cleaner_ui.py` واجهة PyQt بديلة غير مستخدمة في هذا المسار، ولم تتم ترجمته أو اعتماده بهذه التعديلات.

لاختبار الواجهة عبر Wine يمكن ضبط `CDRIVE_CLEANER_THEME=clam` لتجاوز الاعتماد على خدمة المظاهر الأصلية لويندوز؛ هذا خيار للاختبار ولا يغيّر المظهر الافتراضي على ويندوز.
إذا تعطل عرض الخط داخل Wine، يمكن للاختبار استخدام `CDRIVE_CLEANER_FONT=DejaVu Sans`. لا يلزم هذا الإعداد على ويندوز الأصلي.
